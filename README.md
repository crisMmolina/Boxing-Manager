# Evidencia DSK-029 · Inicio con historial y pantalla de carga

Capturas de `InicioScreenshots` (`SIGEBOX_SCREENSHOTS=<carpeta>`, macOS, JavaFX 25), en claro y oscuro, con movimiento reducido para que salgan quietas.

- `01-carga`: logo de guantes de 200 px, SIGEBOX, progreso y "Abriendo la base…".
- `02-carga-error`: error en español y "Reintentar". El logo sale tenue porque se capturó durante el fundido de 150 ms.
- `03-inicio`: 3 eventos del más reciente al más antiguo, con nombre, fecha, peleas y cerradas; "Nuevo evento" es la acción principal y la barra dice Evento · Jueces · En vivo · Resultado, con Inicio activo.
- `04-nuevo-evento`: campos con etiqueta arriba y ejemplo dentro.
- `05-cartelera-anterior`: un evento anterior, solo para consultar.
